خصوصية صورتك أولًا

السياسة دي بتشرح طريقة تعامل النسخة الحالية من الموقع مع الصور والبيانات.

الصور

الصورة اللي بتختارها بتتفتح وتتفحص وتتجهز محليًا في متصفحك. الموقع لا يرفع الصورة إلى سيرفر، ولا يحتفظ بنسخة منها. عند مسح الصورة أو إغلاق الصفحة، المعاينة المحلية بتنتهي.

الحسابات والبيانات

النسخة الحالية لا تطلب تسجيل حساب أو بيانات جواز سفر أو معلومات دفع. لا توجد إعلانات أو أدوات تحليل زيارات مضافة حاليًا. استضافة الموقع قد تسجل بيانات اتصال تقنية عادية مثل عنوان IP وفق سياسة منصة الاستضافة.

روابط خارجية

عند فتح رابط حكومي خارجي، تنتقل لموقع مختلف تسري عليه سياسة الخصوصية الخاصة به. لا ترسل لنا مستنداتك أو صورك عبر رسائل أو روابط غير رسمية.

موقع مستقل غير تابع للحكومة الأمريكية. المعلومات للتوعية، وليست مشورة قانونية أو ضمانًا للقبول.
